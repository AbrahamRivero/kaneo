PalcoDesk includes a powerful global search that lets you find tasks, projects, comments, and activities across all your workspaces.

## Using Global Search

### Accessing Search

There are several ways to access global search:

1. **Keyboard Shortcut**: Press `Ctrl+K` (or `Cmd+K` on Mac) anywhere in the app
2. **Sidebar**: Click on "Search" in the sidebar
3. **Dashboard**: Navigate to /dashboard/search

### Performing a Search

1. Press `Ctrl+K` to open the search dialog
2. Type your search query
3. Results appear as you type
4. Use arrow keys to navigate results
5. Press Enter to select a result

## Search Scope

Global search finds content across:

- **Tasks**: Task titles, descriptions, and comments
- **Projects**: Project names and descriptions
- **Workspaces**: Workspace names
- **Comments**: Task comments and discussion
- **Activities**: Activity log entries

## Filtering Results

You can filter search results by type:

| Filter | Description |
| -------|-------------|
| All | All results |
| Tasks | Only tasks |
| Projects | Only projects |
| Comments | Only comments |
| Activities | Only activities |

## Workspace/Project Filtering

By default, search results include all workspaces you have access to. To narrow results:

<Steps>
<Step>
Click on the filter dropdown in the search bar
</Step>
<Step>
Select a specific workspace or project
</Step>
</Steps>

Results will now be limited to the selected scope.

## Search Behavior

- **Real-time**: Results update as you type
- **Case-insensitive**: Search is case-insensitive
- **Partial matching**: Finds partial matches within titles and content
- **Cached results**: Results are cached for 30 seconds to improve performance

## Search Tips

- **Be specific**: More specific queries return better results
- **Use filters**: Filter by type to find what you need faster
- **Scope down**: Limit to specific workspace/project for focused results

## Keyboard Navigation

When in the search dialog:
- `↑` / `↓`: Navigate results
- `Enter`: Open selected result
- `Escape`: Close search dialog
- `Tab`: Cycle through filter options
