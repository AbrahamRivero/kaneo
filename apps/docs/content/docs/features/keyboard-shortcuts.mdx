PalcoDesk includes keyboard shortcuts to help you navigate quickly and perform common actions without using your mouse.

## Global Shortcuts

These shortcuts work anywhere in the application:

| Shortcut | Action |
| ---------|--------|
| `Ctrl+K` | Open global search |
| `Ctrl+/` | Show keyboard shortcuts help |

## Navigation Shortcuts

| Shortcut | Action |
| ---------|--------|
| `g then d` | Go to Dashboard |
| `g then p` | Go to Projects |
| `g then w` | Go to Workspace Settings |
| `g then s` | Go to Search |
| `g then a` | Go to Analytics |

## Task Shortcuts

| Shortcut | Action |
| ---------|--------|
| `c` | Create new task |
| `f` | Open task filters |
| `e` | Edit selected task |
| `m` | Assign to me |
| `Space` | Open/close selected task |
| `Esc` | Close task detail panel |

## Modifier Keys

Use modifier keys for additional actions:

| Shortcut | Action |
| ---------|--------|
| `Ctrl+Enter` | Save/confirm action |
| `Ctrl+Shift+D` | Toggle dark mode |
| `Ctrl+Shift+L` | Toggle sidebar |

## Using Sequential Shortcuts

Some shortcuts use a sequential pattern (press keys one after another):

1. Press the first key
2. Wait briefly (indicator appears)
3. Press the second key

Example: `g then d`
- Press `g`, wait for indicator
- Press `d` → Navigate to Dashboard

## Shortcut Behavior

- **Context-aware**: Shortcuts are disabled in input fields to prevent accidental triggers
- **Auto-reset**: Sequential shortcuts reset after 2 seconds of inactivity
- **Customizable**: Future versions will support custom keybindings

## Viewing All Shortcuts

To see all available shortcuts at any time:

- Press `Ctrl+/` to open the shortcuts help dialog
- Navigate to Settings > Keyboard Shortcuts (future feature)

## Tips

- Press and hold a modifier key (Ctrl/Cmd) to see context-specific shortcuts
- Use sequential shortcuts for faster navigation once you learn them
- The search shortcut (`Ctrl+K`) is the fastest way to find anything
