PalcoDesk provides comprehensive analytics dashboards for both workspaces and projects. These analytics help you track progress, identify bottlenecks, and measure team productivity.

## Workspace Analytics

The workspace analytics dashboard provides an overview of all projects and tasks within the workspace.

### Accessing Workspace Analytics

<Steps>
<Step>
Navigate to the workspace
</Step>
<Step>
Click on "Analytics" in the sidebar
</Step>
</Steps>

### Available Metrics

#### Task Overview
- **Total Tasks**: Number of tasks across all projects
- **Completed Tasks**: Tasks marked as completed
- **In Progress**: Tasks currently being worked on
- **Backlog**: Tasks waiting to be started

#### Tasks by Status
A breakdown of tasks grouped by their current status:
- Backlog
- To Do
- In Progress
- Technical Review
- Completed
- Archived

#### Tasks by Priority
Distribution of tasks by priority level:
- Urgent
- High
- Medium
- Low
- No Priority

#### Overdue Tasks
Tasks that have passed their due date, grouped by priority. This helps identify tasks requiring immediate attention.

## Project Analytics

Each project has its own analytics dashboard with more detailed metrics.

### Accessing Project Analytics

<Steps>
<Step>
Navigate to the project
</Step>
<Step>
Click on "Analytics" in the project header
</Step>
</Steps>

### Project Metrics

#### Task Completion Rate
Percentage of tasks completed vs. total tasks. Shows project velocity over time.

#### Tasks by Status
Detailed breakdown of task distribution by status within the project.

#### Tasks by Priority
Priority distribution for planning and prioritization.

## Auto-Refresh

The analytics dashboard automatically refreshes every 60 seconds to show the latest data. You can also manually refresh by clicking the refresh button.

## Using Analytics Effectively

### For Project Managers
- Track sprint progress and velocity
- Identify blocked tasks
- Measure team productivity

### For Team Members
- See individual task progress
- Understand workload distribution
- Plan upcoming work

### For Stakeholders
- Get high-level overview of project health
- Review completion rates
- Monitor overdue work
