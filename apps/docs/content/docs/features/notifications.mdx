PalcoDesk keeps you informed about important activities through a notification system. Notifications alert you to task updates, mentions, reservation reminders, and more.

## Notification Types

PalcoDesk generates different types of notifications:

| Type | Description |
| -----|-------------|
| **Task Updates** | Changes to tasks you're assigned to or watching |
| **Mentions** | When someone mentions you in a task or comment |
| **Assignee Changes** | When you're assigned to or unassigned from a task |
| **Due Date Reminders** | Reminders for upcoming or overdue tasks |
| **Reservation Reminders** | Payment reminders for event room reservations |
| **System** | System announcements and updates |

## Viewing Notifications

### Notification Dropdown

Click the bell icon in the header to see recent notifications:

<Steps>
<Step>
Click the bell icon in the top-right corner
</Step>
<Step>
A dropdown shows your recent notifications
</Step>
<Step>
Click on a notification to navigate to the related item
</Step>
</Steps>

### Notification Panel

For a full list, click "View All" in the notification dropdown.

## Marking Notifications

### Mark as Read

Individual notifications can be marked as read:
- Click on the notification to open the related item
- Or click the "Mark as read" action

### Mark All as Read

To mark all notifications as read:

<Steps>
<Step>
Click the bell icon
</Step>
<Step>
Click "Mark all as read"
</Step>
</Steps>

### Clearing Notifications

You can clear all notifications:

<Steps>
<Step>
Click the bell icon
</Step>
<Step>
Click "Clear all"
</Step>
</Steps>

This removes all notifications from the list.

## Notification Settings

Notifications are automatically sent based on your involvement with tasks and projects. Currently, you cannot configure individual notification preferences, but all workspace members receive relevant notifications.

## Reservation Payment Reminders

PalcoDesk sends automated reminders for unpaid reservations:

- **9:00 AM**: First reminder
- **12:00 PM**: Second reminder
- **4:00 PM**: Final reminder

These help ensure clients don't miss payment deadlines.

## Best Practices

- Check notifications regularly to stay on top of task updates
- Mark notifications as read to keep your inbox organized
- Use the clear function to start fresh
