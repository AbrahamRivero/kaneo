The Phone Board is a digital telephone extension board that displays a grid of office extensions. It's useful for offices where employees need to quickly find and call internal extensions.

## Accessing the Phone Board

<Steps>
<Step>
Navigate to the workspace
</Step>
<Step>
Click on "Phone Board" in the sidebar
</Step>
</Steps>

## Phone Board Layout

The phone board displays a grid (50 columns x 10 rows) representing different extensions:

- Each cell represents an internal extension number
- Cells can contain a name and phone number
- Extensions are color-coded by type (digital/analog)

## Cell Types

| Type | Description |
| -----|-------------|
| **Digital** | IP phones or digital extensions |
| **Analog** | Traditional phone lines |
| **Blocked** | Empty or disabled extensions |

## Managing Extensions

### Setting Up Extensions

While the phone board doesn't have a built-in editor in the current version, it's designed to display extension information from a data source.

### Searching Extensions

Use the search function to quickly find an extension:

1. Type a name or number in the search box
2. Results filter in real-time
3. Click on a result to highlight that extension on the board

## Use Cases

- **Office Directory**: Display all employee extensions in a common area
- **Reception**: Help visitors find the right contact
- **Shared Spaces**: Show extensions for common departments or services

## Display Features

- **Visual Grid**: 50x10 grid showing all extensions at a glance
- **Color Coding**: Different colors for digital vs analog extensions
- **Search**: Quick lookup by name or extension number
- **Responsive**: Works on various screen sizes

## Best Practices

- Keep extension data up to date
- Use clear, readable names
- Group related extensions together (by floor or department)
- Place in common areas for maximum utility
