PalcoDesk includes built-in time tracking that allows you to log time spent on tasks. This is useful for billing clients, tracking productivity, or understanding how much time tasks take.

## Starting the Timer

To start tracking time on a task:

<Steps>
<Step>
Open the task you want to track time for
</Step>
<Step>
Scroll to the Time Tracking section
</Step>
<Step>
Click the play button to start the timer
</Step>
</Steps>

The timer will begin counting. You can see the elapsed time in real-time.

## Stopping the Timer

To stop the timer:

<Steps>
<Step>
Click the stop button on the active timer
</Step>
<Step>
Optionally add a description for the time entry
</Step>
<Step>
Click "Save" to record the time entry
</Step>
</Steps>

The time entry will be saved to the task with the duration and timestamp.

## Manual Time Entry

You can also log time manually without using the timer:

<Steps>
<Step>
Open the task
</Step>
<Step>
Click "Add Time Entry" in the Time Tracking section
</Step>
<Step>
Enter the duration (hours and minutes)
</Step>
<Step>
Optionally add a description
</Step>
<Step>
Click "Save"
</Step>
</Steps>

## Viewing Time Entries

All time entries for a task are displayed in the Time Tracking section, showing:
- Date and time of the entry
- Duration
- User who logged the time
- Description (if provided)

## Managing Time Entries

You can edit or delete existing time entries:

- **Edit**: Click on a time entry to modify the duration or description
- **Delete**: Click the delete icon to remove a time entry

## Time Entry Properties

| Property | Description |
| -------- | ----------- |
| **Duration** | Time spent (hours:minutes) |
| **Description** | Optional notes about what was done |
| **Date** | When the time was logged |
| **User** | Who logged the time |

## Viewing Total Time

The task detail view shows the total time logged across all entries. This helps you understand the total effort required for each task.

## Accessing Time Reports

To view time tracking reports across your workspace:

<Steps>
<Step>
Navigate to the workspace
</Step>
<Step>
Click on "Analytics" in the sidebar
</Step>
</Steps>

The analytics dashboard includes time tracking metrics showing:
- Total time logged by team members
- Time by project
- Time by task

## Best Practices

- **Log regularly**: Stop the timer and log time when you finish a task or take a break
- **Add descriptions**: Include brief descriptions to help remember what was done
- **Use for estimates**: Historical time entries help estimate future task durations
