PalcoDesk is an open source project management platform focused on simplicity and efficiency. This comprehensive guide will help you get up and running quickly with a production-ready setup.

## Why Choose PalcoDesk?

- **🚀 Fast Setup**: Get running in under 5 minutes with Docker Compose
- **🔒 Self-Hosted**: Your data stays on your infrastructure
- **🛠️ Customizable**: Open source and built for extensibility
- **📊 PostgreSQL**: Reliable database with proper data integrity
- **📅 Event Rooms**: Built-in room reservation and booking system
- **📞 Phone Board**: Digital telephone extension board
- **📈 Analytics**: Real-time workspace and project analytics
- **🔗 GitHub Integration**: Sync tasks with GitHub issues

## Docker Compose Installation

The easiest way to get started with PalcoDesk is using Docker Compose:

<Steps>
<Step>
**Create your Docker Compose configuration**

Create a `compose.yml` file with the following content:
</Step>

```yaml
services:
  postgres:
    image: postgres:16-alpine
    environment:
      POSTGRES_DB: PalcoDesk
      POSTGRES_USER: PalcoDesk_user
      POSTGRES_PASSWORD: PalcoDesk_password
    volumes:
      - postgres_data:/var/lib/postgresql/data
    restart: unless-stopped

  api:
    image: ghcr.io/kaneo/api:latest
    environment:
      JWT_ACCESS: "your_secure_jwt_token"
      DATABASE_URL: "postgresql://PalcoDesk_user:PalcoDesk_password@postgres:5432/PalcoDesk"
      DISCORD_CLIENT_ID: ""
      DISCORD_CLIENT_SECRET: ""
      GITHUB_CLIENT_ID: ""
      GITHUB_CLIENT_SECRET: ""
      DEMO_MODE: "false"
      CORS_ORIGIN: "http://localhost:5173"
    ports:
      - 1337:1337
    depends_on:
      - postgres
    restart: unless-stopped

  web:
    image: ghcr.io/kaneo/web:latest
    environment:
      PalcoDesk_API_URL: "http://localhost:1337"
    ports:
      - 5173:5173
    depends_on:
      - api
    restart: unless-stopped

  docs:
    image: ghcr.io/kaneo/docs:latest
    ports:
      - 5174:5173
    depends_on:
      - api
    restart: unless-stopped

volumes:
  postgres_data:
```

<Step>
**Start the services**

Run the following command to start all services:

```bash
docker compose up -d
```

This will download the images and start the containers in the background.
</Step>

<Step>
**Access your PalcoDesk instance**

Open [http://localhost:5173](http://localhost:5173) in your browser.
</Step>

<Step>
**Create your first workspace**

After signing up, you'll be guided through creating your first workspace where you can organize projects and team members.

You'll be able to:
- Create projects and organize tasks
- Assign team members and set priorities
- Track progress with kanban boards
- Manage event room reservations
- Collaborate with your team in real-time
</Step>

</Steps>

## Environment Variables Reference

| Variable | Description | Required | Default |
| -------- | ----------- | -------- | ------- |
| `PalcoDesk_API_URL` | The URL where the API is accessible | Yes | - |
| `JWT_ACCESS` | Secret key for generating JWT tokens | Yes | - |
| `DATABASE_URL` | PostgreSQL connection string | Yes | - |
| `DISABLE_REGISTRATION` | Enable/disable new user registration | No | `false` |
| `DEMO_MODE` | Enable demo mode with sample data | No | `false` |
| `CORS_ORIGIN` | Allowed CORS origins | No | `*` |
| `DISCORD_CLIENT_ID` | Discord OAuth client ID | No | - |
| `DISCORD_CLIENT_SECRET` | Discord OAuth client secret | No | - |
| `GITHUB_CLIENT_ID` | GitHub OAuth client ID | No | - |
| `GITHUB_CLIENT_SECRET` | GitHub OAuth client secret | No | - |

## Demo Mode

PalcoDesk supports a demo mode that loads sample data so you can explore the platform without setting up a database:

```yaml
services:
  api:
    image: ghcr.io/kaneo/api:latest
    environment:
      JWT_ACCESS: "demo_secret_key"
      DEMO_MODE: "true"
    # ... other config
```

Demo mode includes:
- Sample workspaces, projects, and tasks
- Example event rooms and reservations
- Pre-configured labels and team members
- Analytics with sample data

## Database Setup

PalcoDesk uses PostgreSQL for reliable data storage. The Docker Compose setup above handles this automatically:

### Manual PostgreSQL Setup

1. **Install PostgreSQL** (version 12 or higher)
   ```bash
   # Ubuntu/Debian
   sudo apt install postgresql postgresql-contrib

   # macOS with Homebrew
   brew install postgresql
   ```

2. **Create a database and user:**
   ```sql
   CREATE DATABASE PalcoDesk;
   CREATE USER PalcoDesk_user WITH PASSWORD 'your_password';
   GRANT ALL PRIVILEGES ON DATABASE PalcoDesk TO PalcoDesk_user;
   ```

3. **Set the DATABASE_URL environment variable:**
   ```bash
   export DATABASE_URL="postgresql://PalcoDesk_user:your_password@localhost:5432/PalcoDesk"
   ```

## Security Considerations

For production deployments, make sure to:

- **Change default passwords**: Use strong, unique passwords for JWT_ACCESS and database credentials
- **Use HTTPS**: Deploy behind a reverse proxy with SSL/TLS certificates
- **Regular backups**: Set up automated database backups
- **Update regularly**: Keep your PalcoDesk installation up to date
- **Configure CORS**: Set CORS_ORIGIN to your specific domain in production

## PalcoDesk Features Overview

PalcoDesk offers a comprehensive set of features for project management:

### Core Features
- **Workspaces**: Top-level organization for teams and projects
- **Projects**: Group related tasks together
- **Tasks**: Kanban boards, backlog views, time tracking
- **Teams**: Role-based access control (owner, member, viewer)

### Advanced Features
- **Event Rooms**: Room reservation and booking system
- **Phone Board**: Digital telephone extension board
- **Analytics**: Real-time workspace and project metrics
- **GitHub Integration**: Sync tasks with GitHub issues
- **Global Search**: Find tasks, projects, and more across workspaces
- **Public Projects**: Share projects with external users

### User Experience
- **Keyboard Shortcuts**: Navigate quickly with keyboard commands
- **Theme Settings**: Light/dark mode support
- **Notifications**: Stay updated on task changes and reservations
- **Import/Export**: Import tasks from JSON, export for analysis
