## What are Workspaces?

Workspaces are the top-level organizational units in PalcoDesk. They serve as containers for projects, tasks, team members, and event rooms. Think of a workspace as a dedicated space for a specific team, department, or area of work.

## Creating a Workspace

To create a new workspace:

<Steps>
<Step>
Click on the workspace selector in the top-left corner
</Step>
<Step>
Select "Create Workspace"
</Step>
<Step>
Enter a name for your workspace
</Step>
<Step>
Click "Create"
</Step>
</Steps>

## Workspace Features

Each workspace comes with a comprehensive set of features:

### Project Management
- Create and manage multiple projects
- Organize tasks with kanban boards and backlog views
- Track project progress with analytics

### Team Collaboration
- Invite team members with different roles
- Assign tasks to workspace members
- Monitor team activity through the activity feed

### Event Rooms
- Manage physical or virtual rooms for reservations
- Set up pricing tariffs for different session types
- Add services like catering and equipment

### Analytics
- View workspace-wide metrics
- Track overdue tasks by priority
- Monitor team productivity

## Managing Workspace Settings

Each workspace has its own settings that you can configure:

<Steps>
<Step>
Click on the workspace selector in the top-left corner
</Step>
<Step>
Select the workspace you want to manage
</Step>
<Step>
Click on "Settings" in the sidebar
</Step>
</Steps>

From the settings page, you can:
- Update the workspace name and description
- Configure workspace-specific feature flags
- Delete the workspace

## Switching Between Workspaces

If you belong to multiple workspaces, you can easily switch between them:

<Steps>
<Step>
Click on the workspace selector in the top-left corner
</Step>
<Step>
Select the workspace you want to switch to
</Step>
</Steps>

## Deleting a Workspace

To delete a workspace:

<Steps>
<Step>
Navigate to the workspace settings
</Step>
<Step>
Scroll to the bottom of the page
</Step>
<Step>
Click on "Delete Workspace"
</Step>
<Step>
Confirm the deletion
</Step>
</Steps>

**Note**: Deleting a workspace will permanently remove all projects, tasks, event rooms, reservations, and data associated with it. This action cannot be undone.

## Workspace Routes

The workspace provides access to various sections:

| Route | Description |
| ------|-------------|
| `/workspace/:id` | Workspace overview and projects list |
| `/workspace/:id/members` | Team member management |
| `/workspace/:id/settings` | Workspace configuration |
| `/workspace/:id/analytics` | Workspace analytics dashboard |
| `/workspace/:id/event-rooms` | Event room reservations |
| `/workspace/:id/phone-board` | Phone board for the workspace |
