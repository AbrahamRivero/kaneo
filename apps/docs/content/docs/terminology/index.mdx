PalcoDesk is built around a set of core concepts that help you organize and manage your work effectively. This guide provides an overview of these concepts and how they relate to each other.

## Core Entities

PalcoDesk organizes your work using the following key entities:

### Organizational Entities
- **[Workspaces](/docs/terminology/workspaces)**: The top-level organizational unit that contains projects, team members, and event rooms
- **[Projects](/docs/terminology/projects)**: Collections of related tasks within a workspace
- **[Tasks](/docs/terminology/tasks)**: Individual work items that need to be completed
- **[Teams](/docs/terminology/teams)**: Groups of users who collaborate on workspaces and projects

### Tracking & Management
- **Time Entries**: Records of time spent working on tasks
- **Labels**: Color-coded tags for categorizing tasks
- **Activities**: Audit trail of all changes made to tasks

### Event Management
- **Event Rooms**: Physical or virtual spaces available for reservation
- **Services**: Additional offerings (catering, equipment) that can be added to reservations
- **Tariffs**: Pricing rules for different session types
- **Reservations**: Bookings for event rooms with date ranges and client details

### Communication
- **Notifications**: System alerts for task updates, mentions, and reservation reminders
- **Comments**: Discussion threads attached to tasks

## Supporting Features

### Views & Navigation
- **Kanban Board**: Visual task management with drag-and-drop columns
- **Backlog View**: List of tasks not yet started or in progress
- **List View**: Tabular view of all tasks in a project
- **Public Project View**: Read-only view for external stakeholders

### Tools
- **Phone Board**: Digital telephone extension board for office communications
- **Analytics Dashboard**: Real-time metrics on workspace and project performance
- **Global Search**: Search across all tasks, projects, and workspaces
- **GitHub Integration**: Sync tasks with GitHub repositories


## Task Statuses

PalcoDesk tasks move through the following statuses:

- **Backlog**: Tasks not yet started, waiting in the queue
- **To Do**: Tasks ready to be worked on
- **In Progress**: Tasks currently being worked on
- **Technical Review**: Tasks awaiting review
- **Completed**: Tasks finished and done
- **Archived**: Old tasks archived for reference

## Priority Levels

Tasks can be assigned priority levels:

- **No Priority**: No specific priority assigned
- **Low**: Can be addressed when time permits
- **Medium**: Standard priority
- **High**: Should be addressed soon
- **Urgent**: Requires immediate attention

## User Roles

Workspace members can have different roles:

- **Owner**: Full access to all workspace features and settings
- **Member**: Can create and manage projects and tasks
- **Viewer**: Read-only access to workspace content

Each of these concepts is explained in detail in the corresponding documentation pages.
